# Vaciada Paradox

> Why Spain is filling with tourists and emptying of Spaniards

## Overview
This project examines overtourism across the European Union, with a focus on Spain. Specifically, this study tests whether the tourism concentration map and depopulation map are actually the same. Methods used include inequality statistics applied spatially and a causal layer that tests the effectiveness of tourism policies.

## Methods
- **Gini, Theil, concentration ratio** for measuring how lopsided tourism is
- **K-Means clustering with PCA** for the region typology
- **Synthetic control** for the causal section around a real tourism policy
- **DuckDB** for the SQL-based data pipeline
- **Bootstrap** for stability
